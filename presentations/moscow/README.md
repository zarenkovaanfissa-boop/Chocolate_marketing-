# Презентация «Упаковка «Москва»»

- `moscow-packaging-3d.pptx` — версия 2026: Glossy 3D + стекло, 4 слайда, текст редактируется.
- `moscow-packaging-3d.pdf` — превью с правильными шрифтами.
- `moscow-packaging-v1-flat.pptx` — первая плоская версия.
- `fonts/` — Unbounded (заголовки) и Onest (текст), лицензия SIL OFL. Установите их перед открытием .pptx, иначе PowerPoint подставит другие шрифты.

3D-графика (плитки, малина, цифры, стеклянные карточки, диаграмма) запечена в фон слайдов. Текст поверх неё живой. Если менять текст или цифры диаграммы, графику нужно перерисовать.
